# StudyConnect

## Project Description

StudyConnect is a web platform designed to help university students find study partners, organize study sessions and create project teams.

Students can browse study opportunities, search and filter announcements, create posts and apply to join groups.

## Main Features

- User registration and login.
- Student profiles.
- Creating study sessions and project teams.
- Searching and filtering posts.
- Applying to join groups.
- Managing applications.
- Group chat.
- StudyConnect statistics.
- Smart Study Environment.

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Firebase Hosting

## How to Run the Project

1. Open the GitHub repository: [https://github.com/gaukharonly/studyconnect](https://github.com/gaukharonly/studyconnect)
2. Download or clone the project.
3. Open the project folder in Visual Studio Code.
4. Install the Live Server extension.
5. Open `index.html`.
6. Click **Go Live** to run the website.

## User Roles

**Student**

- Browse study opportunities.
- Create study posts.
- Search and filter announcements.
- Apply to join groups.
- Communicate with group participants.

**Organizer**

- Create study sessions and project teams.
- Review and manage applications.
- Communicate with group participants.

**Administrator**

- Access the administration panel.
- Moderate content.
- Review reports and manage inappropriate posts.

## Smart Study Environment

The Smart Study Environment provides information about the study environment, including temperature and humidity levels. It displays environmental readings and shows whether the conditions are comfortable for studying.
